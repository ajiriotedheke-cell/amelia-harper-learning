FOR PARENTS AND CAREGIVERS

Privacy & safety

Children's wellbeing and privacy matter. This page describes the limited gameplay analytics currently implemented in the website code and highlights the protections that must be completed before public launch.

Launch status: draft notice. This is not a legally reviewed privacy policy. The website operator's legal identity, contact details, hosting logs, retention periods, user-rights process, consent requirements and country-specific disclosures must be confirmed before launch.

How children should use the website

Amelia Harper is designed for children to use with parent or caregiver supervision. Social media, external shopping and other outbound links are intended for adults. Please help children navigate to the games and listening activities they want.

Gameplay analytics in the current code

The ABC game can send aggregate start and completion events. The event endpoint is designed to store:

  • Game slug and event type (for example, game start or completion).
  • A broad age-band selection, not a date of birth.
  • A broad device category (mobile, tablet or desktop).
  • A country code supplied by the hosting platform, where available.
  • The event timestamp recorded by the database.

The current game code does not intentionally send a child's name, email address, selected answers, precise location or a persistent player identifier to this analytics endpoint. This does not mean the hosting provider or external services never process technical data such as IP addresses; those practices must be checked and disclosed separately.

External services and links

The workbook purchase link opens Gumroad. Social links may open third-party platforms when an administrator configures them. Those services have their own privacy practices and terms. Parents should review them before use or purchase.

Data retention and parent requests

A production retention schedule, deletion process and contact channel have not yet been configured in this starter project. Before launch, the operator must decide how long analytics records are kept, how parents can ask questions or exercise applicable privacy rights, and who handles those requests.

Safety and advertising

Do not add behavioural advertising, child profiles, public comments or direct messaging without a separate child-safety, privacy and legal review. Any future advertising must be assessed for child-directed compliance and must not interrupt games or bedtime audio.

Contact

Official operator name and parent privacy contact details will be published here before the website is opened to the public.
